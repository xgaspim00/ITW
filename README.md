## ℹ️ About the Project
This repository contains the source code for a static presentation website created based on an assignment in the 1st year at FIT VUT. The project demonstrates the use of core web technologies without using complex frameworks.

> **⚠️ Important Notice Regarding Responsiveness:**
> The responsive design was not fully completed. The webpage is currently **fully optimized for PC (desktop) viewing only**. When viewed on mobile devices, tablets, or in small browser windows, the content may not display and wrap correctly.

## 🛠️ Built With
* **HTML5:** Content structure
* **CSS3:** Design and layout (`css/style.css`)
* **JavaScript (Vanilla JS):** Interactive web elements (slider, toast notifications, scrolling, video controls)

## 📂 Project Structure
* `index.html` - Main page document
* `css/` - Folder containing stylesheets
* `js/` - Folder containing JavaScript files
* `img/` - Raster and vector images used on the website
* `video/` - Video assets
